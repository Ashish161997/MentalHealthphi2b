**Mental Health LLM Model**

**Overview**

Welcome to the Mental Health LLM (Language Model) Model repository! This project aims to provide advice and support on mental health-related questions using cutting-edge natural language processing techniques.

**Features**

**Phi2 Model**: Our model utilizes the Phi2 architecture, a state-of-the-art LLM model with 2 billion parameters.

**Advice Generation**: The model is trained to generate personalized advice and guidance for various mental health concerns.

**User Interaction**: Users can interact with the model by inputting their questions or concerns related to mental health. (Using Gradio app)
